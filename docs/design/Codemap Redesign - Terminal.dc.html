codemap (no args) — the front door
$ codemap

codemap — a live map of your codebase that follows your coding agent

  start [path]        index, serve the UI, listen for hooks
  ticker [path]       text pane for tmux beside your agent
  status · stop       daemon lifecycle

  index <path>        summary + call-resolution coverage, no daemon
  reach <path> <sym>  which routes reach a symbol, no daemon
  install-hooks       claude · codex · gemini

Nothing runs until you start it. No telemetry, loopback only.
